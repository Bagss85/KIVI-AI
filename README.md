# KIVI AI — стартовый проект

Это первая заготовка приложения для Android TV. Сейчас в ней есть:
- TV-экран KIVI AI;
- управление интерфейсом стрелками и кнопкой OK на пульте;
- тестовая кнопка «Начать разговор»;
- заготовленные разрешения для интернета и микрофона;
- GitHub Actions для автоматической сборки APK.

## Важно
Это пока НЕ готовый голосовой ИИ. Микрофон, OpenAI API и команды управления телевизором ещё не подключены.
Не вставляйте секретный OpenAI API-ключ в Android-приложение. Для полноценного подключения понадобится защищённый сервер.

## Сборка
Нужны JDK 17 и Gradle 8.9:
```bash
gradle :app:assembleDebug
```
APK появится здесь:
`app/build/outputs/apk/debug/app-debug.apk`

## Сборка без компьютера
1. Создайте репозиторий GitHub с именем `KIVI-AI`.
2. Загрузите в него содержимое этого архива.
3. Откройте вкладку Actions.
4. Запустите workflow `Build KIVI AI APK` (или дождитесь сборки после push).
5. В завершившемся запуске скачайте artifact `KIVI-AI-debug`.
